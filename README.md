# Darcy-Weisbach Fluid Flow & Pipe Friction Mini-App

This interactive web application calculates pipe friction head loss and pressure drop using the classic Darcy-Weisbach equation and Swamee-Jain friction factor correlations. Built with Streamlit, Python, and Plotly, the app allows engineers to adjust fluid density, dynamic viscosity, pipe inner diameter, length, and flow velocity to analyze flow regimes and visualize how head loss scales inversely with pipe diameter.
